# Module 8 datasets

- `honeybot_training_dataset.csv` — balanced synthetic training set (3600 sessions,
  600/class × 6 classes), 29 features + `label`. Generated by `ml/synth.py`.
- `honeybot_live_dataset.csv` — real honeypot sessions captured from the live stack
  (rule-based weak labels), built by `ml/features.py`. Regenerate with
  `python -m ml.features out.csv` or `GET /api/ml/dataset.csv`.

See `docs/MODEL_EVALUATION.md` for the trained-model accuracy (held-out test,
confusion matrix) and an honest reading of the numbers.
